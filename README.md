# Учебная практика по профессиональному модулю ПМ 11
Специальность: 09.02.07 «Информационные системы и программирование»

## Описание проекта
Данный репозиторий содержит материалы учебной практики студента группы ИСП-33 Медведева Б.А.
Предметная область: **Интернет-магазин цифровой техники**.

## Состав репозитория
1. **Отчеты**:
   - `Отчет по УП Медведев Исп33.docx` — полный отчет по практике (17 тем).
   - `Дневник_Медведев.docx` — заполненный дневник практики.
   - `Аттестационный_лист_Медведев.docx` — аттестационный лист.
2. **База данных**:
   - `internet_shop_db.sql` — SQL-скрипт для создания структуры БД (PostgreSQL) и наполнения её начальными данными.

## Ключевые разделы отчета
- Техника безопасности и компьютерная гигиена.
- Проектирование реляционной БД (Концептуальная и Логическая модели).
- Нормализация таблиц (3НФ).
- Разработка сложных SQL-запросов, вьюх (VIEW) и хранимых процедур.
- Настройка резервного копирования и восстановления данных.
